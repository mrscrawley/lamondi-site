# lamondi — сайт (Bayreuth)

Статический сайт суши-ресторана Lamondi (Bahnhofstraße 23, Bayreuth) в стиле
uchi.uchirestaurants.com. Языки DE (по умолчанию) и EN.

Онлайн: https://mrscrawley.github.io/lamondi-site/ (GitHub Pages, ветка main, обновляется после push).

Запуск локально: `python3 -m http.server 8741 --directory lamondi-site` → http://localhost:8741

## Где что менять
- **Палитра** — переменные в начале `css/style.css` (`:root`), снята с фото зала: главный оранжевый
  `--brand`, янтарь светящихся ниш `--amber`, тёплый белый фон, тёмное дерево.
- **Логотип** — отдельного нет, лого = слово «lamondi»; точка над i — светящаяся квадратная ниша
  (отсылка к стене-шахматке). Разметка: `<span class="lm">lamond<span class="idot">ı</span></span>`.
- **Стена с нишами** — белая стена, ниши в шахматном порядке со статуэтками (силуэты `FIGS`); полоса под фото и секция «die leuchtwand» (клик гасит/зажигает нишу);
  строятся в `initLightWall()` в `js/site.js`.
- **Контакты, часы, e-mail, Instagram** — `CONFIG` в начале `js/site.js`.
- **Меню** — `js/menu-data.js`, перенесено с бумажного меню (28.10.2026): три части — asiatisch (серые страницы),
  mediterran (оранжевые), bar. Номера Zusatzstoffe (`z`) и их список `ADDITIVES` — как в бумажном меню.
- **Тексты** — прямо в HTML, двуязычно: `<span data-l="de">…</span><span data-l="en">…</span>`.
- **Видео на главной** — положить `assets/video.mp4` (H.264) и раскомментировать `<video>` в `index.html`.

## Фото, шрифт, превью
- Сайт показывает **WebP** (`*.webp`, для широких ещё `*-800.webp` под телефон). После замены любого JPG
  в `assets/img` запустить `python3 _gen/webp.py`, иначе на сайте останется старое фото.
- Шрифт Outfit лежит локально в `assets/fonts` (без Google Fonts).
- Превью ссылки — `assets/og-image.jpg` (макет `_gen/og/og.html`). `og:image`/`og:url` сейчас указывают на
  GitHub Pages (https://mrscrawley.github.io/lamondi-site/) — при переезде на свой домен заменить во всех HTML.
- Стена: `assets/img/wand-nische.jpg` (über uns) и `wand-nischen.jpg` — визуализации по фото зала (`_ref/t01`, `t15`).
- Ниши на сайте (полоса и «die leuchtwand») — студийные кадры каждой ниши по одному шаблону (фронтально, предмет
  по центру): исходники `_gen/niches2/*.png` → `python3 _gen/niche_crop.py` (обрезка точно по проёму) →
  `assets/img/niches/*.webp`. Список — `NICHES`/`CORAL` в site.js; коралловая — примерно каждая четвёртая, вразброс (6 вариантов); после niche_crop.py коралловым добавлять насыщенность ×1.3. wallHTML следит, чтобы одинаковые фигуры не стояли ближе двух клеток.
- Производительность: никаких CSS-фильтров на множестве элементов (drop-shadow тормозил скролл);
  полоса ниш двигается через `transform` только когда видна.
- Плавная инерционная прокрутка — Lenis 1.1.13 (как на сайте «Родос»), файл локально `assets/js/lenis.min.js`;
  только мышь/тачпад, на телефоне родная прокрутка. Карусель «lieblingsgerichte» — своя физика:
  лента догоняет цель, свайп/перетаскивание с инерцией и мягкой доводкой, бесконечная по кругу.
- Главная: логотип в шапке скрыт, большое «lamondi» при скролле уменьшается и уезжает в левый верхний угол
  (`initLogoDock` в site.js: fixed-копия слова двигается transform'ом, классы `dock` / `dock-in` на <html>).
- Ссылки на css/js/фото с `?v=N` — при правке файла увеличить N, чтобы у посетителей не остался старый кэш.

## Заглушки (заменить до запуска)
- Фото блюд (`assets/img/dish-*.jpg`) — реальные блюда Lamondi: фото гостей с TripAdvisor (`_ref/`, на сайт
  не идут) пересняты в Higgsfield (Nano Banana 2.1) строго сверху на угольном фоне, фон заменён на цвет сайта
  скриптом `_gen/ondark.py` (для доски с суши — построчная маска по цвету дерева). Сырые кадры в `_gen/raw/`.
- После вырезки все фото прогоняются через `_gen/grade.py` (светлее и теплее, фон не трогает);
  исходники до грейдинга — `_gen/pre_grade/`.
- Фото суши-меню (52 позиции) — `assets/img/sushi/<id>.jpg` + миниатюра `<id>-s.jpg`; в меню поле `img`.
  Конвейер: Higgsfield (референс — доска с суши) → `_gen/menu/fetch.sh` (вырезка доски + грейдинг) →
  `_gen/menu/build.py`. Ход генерации и id задач — `_gen/menu/jobs.txt`.
  Раскладка: нигири поперёк доски; Sushi Mix — сверху нигири/гунканы, снизу маки срезом вверх; hoso 2×3.
- Блюда на тарелках обрезаются по точному кругу: `python3 _gen/plate.py src dst [--dark-bg] [--rim]`
  (`--rim` — мягкий ободок, чтобы белая тарелка не терялась на светлом фоне).
- Суши всегда на плоской деревянной доске (у ресторана нет посуды с ячейками), ровными рядами; доску вырезает `_gen/woodboard.py`.
- Стоковых фото Unsplash на сайте больше нет (interior2/cocktail/lamps лежат, но не используются).
- Фото сотрудников на сайте не используются.
- E-mail не указан (уточняется): форма брони пока предлагает позвонить.
- Datenschutz — черновик, проверить у юриста. Шрифт Outfit грузится с Google Fonts —
  для DSGVO лучше держать его локально.
- Impressum взят со старого сайта sushi-bayreuth.com — проверить актуальность.
